# Alignment with uploaded Smart Glasses reports

- Project title: **Profile Analyser Through Smart Glasses**.
- Project goal: identify enrolled students from an image and display their profiles to faculty using smart glasses.
- Proposed five fields: hall-ticket ID, name, mobile number, photograph, hobbies.
- Proposed hardware: camera, mini processing unit, projector, spectacles lenses and frame.
- **Implemented software:** OpenCV face detection and explicit-ID lookup on fictional profiles.
- **Not implemented:** biometric face-to-identity matching, smart-glasses hardware, near-eye display, validated identification accuracy.
- **Execution:** three automated tests passed; an earlier image run returned three detected face regions.
- **Privacy:** uploaded XLSX files include personally identifiable data; original student photos and datasets are not published. Face datasets are not bundled due to unknown consent and redistribution permissions.
